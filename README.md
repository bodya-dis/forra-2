# FORRA RESIDENCE — hero

The animated hero of the FORRA RESIDENCE website (Carpathians, Hirne Village): the house construction film, the drafting reveal of the title, the dial numbers and the scroll room tour (floor plan → living room → bedroom → bathroom).

Static site: `index.html` plus `assets/`. GSAP 3.12.5 and ScrollTrigger load from cdnjs; fonts from Google Fonts.

Run locally: `npx serve .` (or any static server) and open the printed address.
